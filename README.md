# Миграция MS SQL Server → Tantor 18 (PostgreSQL 18)

Проект: методика и рабочие инструкции по переносу базы данных MS SQL Server в СУБД Tantor 18
(ядро PostgreSQL 18) средствами pgloader — от инвентаризации источника до приёмки и отката.

## Структура репозитория

```
План.md                  план верхнего уровня (нумерация разделов = ссылки из инструкций)
docs/13.x-*.md           пошаговые инструкции по разделам 13 плана
tools/                   генераторы и вспомогательные скрипты (без данных заказчика)
```

Рабочие выгрузки — инвентарь, снимки, копии, DACPAC — хранятся **вне репозитория**
(см. `.gitignore` и раздел 1 инструкции 13.1).

## Правила ведения

- Документы — в Markdown, на русском; даты абсолютные (`YYYY-MM-DD`).
- Факты о поведении инструментов подтверждаются документацией и фиксируются ссылкой на источник.
- Скрипты проверяются на тестовой БД перед применением к рабочей; в инструкциях это указано там,
  где проверка обязательна.
- Один логический шаг на коммит; сообщения вида `<область>: <что изменилось>`.
- Пароли, строки подключения и данные заказчика в репозиторий не попадают.
