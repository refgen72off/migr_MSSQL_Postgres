# Миграция MS SQL Server → Tantor 18 (PostgreSQL 18)

Проект: методика и рабочие инструкции по переносу базы данных MS SQL Server в СУБД Tantor 18
(ядро PostgreSQL 18) средствами pgloader — от инвентаризации источника до приёмки и отката.

## Артефакты

| Файл | Что внутри |
|---|---|
| [План.md](План.md) | План верхнего уровня, v0.2: границы pgloader и штатные соответствия типов, стратегия переноса и механизмы дельты, 12 этапов с критериями готовности, технические решения, валидация, переключение приложения, откат, риски, открытые вопросы |

Следующий артефакт — подробная пошаговая инструкция (состав зафиксирован в разделе 13 плана):
команды, разбор загрузочного файла, каталог ошибок, чек-лист приёмки, последовательность
переключения и отката.

## Статус

План в редакции v0.2 (2026-11-18). Ожидает исходных данных по системе (раздел 2 плана) и ответов
на открытые вопросы (раздел 12): объём и критичность, доступность окна остановки записи,
наличие и владелец хранимого кода, требования к правам.

## Правила ведения

- Документы — в Markdown, на русском; даты абсолютные (`YYYY-MM-DD`).
- Факты о поведении инструментов подтверждаются документацией и фиксируются ссылкой на источник.
- Один логический шаг на коммит; сообщения вида `<область>: <что изменилось>`.
- Пароли, строки подключения и данные заказчика в репозиторий не попадают.
