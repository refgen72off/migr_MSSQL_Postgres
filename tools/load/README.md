# Загрузочные файлы pgloader: ONEC_MIMIC → Tantor 18

Этап 13.7. Файлы не содержат секретов и имён хостов — все значения в `{{скобках}}`
подставляются из переменных окружения (mustache-шаблоны pgloader).

## Состав и порядок запуска

| Порядок | Файл | Что грузит | Объём |
|---|---|---|---|
| 1 | `onec-mimic-main.load` | все таблицы, кроме вынесенных | 76 таблиц, ~7,4 млн строк |
| 2 | `onec-mimic-accumrg1.load` | `dbo._AccumRg1` | 4 268 000 строк |
| 3 | `onec-mimic-files.load` | `dbo._Files` | 4 050 строк, ~2 ГБ LOB |

Порядок: сначала мелкие таблицы (быстро видны ошибки типов), затем крупные, затем LOB
(13.7 §3).

## Переменные окружения

```bash
export MSSQL_USER=migr_reader           # db_datareader + VIEW DEFINITION (13.6 §3)
export MSSQL_HOST=...                  # хост MSSQL
export MSSQL_DB=ONEC_MIMIC
export MSSQL_PWD=...                   # из защищённого хранилища, не в истории shell
export PG_USER=migr_etl                 # владелец схемы (13.5)
export PG_HOST=...                     # хост Tantor
export PG_DB=onec_mimic
export PG_PWD=...                      # пароль migr_etl
```

Пароли не URL-кодируются автоматически: в них не должно быть `@ : / % #` (13.6 §4) — иначе
сменить на не содержащие спецсимволов.

## Запуск

```bash
pgloader --verbose --summary main.summary.csv \
         --root-dir /var/local/pgloader \
         tools/load/onec-mimic-main.load
```

`--root-dir` — на реальном диске, не в tmpfs: в `/tmp` (1,9 ГБ) батчи LOB не поместятся.
`--summary` — вход для протокола прогона (13.8) и сверки строк (13.10).

## Что делается вручную (не pgloader)

- **FK** — в базе отсутствуют (13.4 §7), создавать нечего.
- **Identity** (16 колонок в `gen`): pgloader переносит как `integer`; на этапе 13.9 —
  `GENERATED BY DEFAULT AS IDENTITY` + `setval` до `ident_current` источника.
- **rowversion-колонки** (22): переносятся как `bytea` (см. CAST), дропаются на этапе 13.9.
- **CHECK/DEFAULT** — отсутствуют.
- `ALTER SCHEMA 'dbo' RENAME TO 'public'` — выполняется самим файлом.

## Повторный прогон

`truncate` + `include no drop`: повторный запуск перезаливает таблицы целиком (pgloader
не умеет догрузку изменений; «догон» — только `MATERIALIZE VIEWS` по времени, 13.7 §4).
Схемы `public`/`gen` должны существовать до прогона (`create no schemas` в файлах).
